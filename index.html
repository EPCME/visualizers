Note Visualizer

Load a MusicXML score and a mapping file, and every note is replaced by the word you've mapped it to. Everything runs in your browser; nothing is uploaded anywhere.

Mapping file format

Each line gives a note and the text to show for it. Use =, : or a tab between them. Lines starting with # or // are comments.

# every G, in any octave
G = cheese
# a sharp or flat (♯ and ♭ work too)
F# = lime
Bb = blueberry
# one specific octave, which beats the plain rule
G5 = gouda
rest = ...
# a picture, by URL (the label in [ ] is optional; it shows on hover and in copied text)
A = ![apple](https://example.com/apple.png)
# anything not matched above
* = ?

Or as JSON: {"G": "cheese", "A": {"image": "https://…/apple.png", "text": "apple"}}

Pictures you upload in the rule editor are shrunk and stored inside the mapping itself (as data: URLs), so a downloaded mapping file carries its pictures with it. Your current mapping is also remembered in this browser between visits.

Each note is matched from the most specific rule to the least: the exact spelling with its octave (F#4), the spelling alone (F#), the enharmonic equivalent (Gb4, then Gb), and finally *. A note that matches nothing shows its own name, highlighted.

Loading from a URL only works when the server allows cross-origin requests (CORS). GitHub raw links (raw.githubusercontent.com) and Gists work. If a URL won't load, download the file and choose it instead.

Sharing

Copy share link works when the score was loaded from a URL and the mapping uses only text and picture URLs. Uploaded pictures are too big to fit in a link. A mapping built or edited on the page travels compressed inside the link, so nothing else needs hosting. Opening a shared link doesn't replace your own saved mapping unless you edit what you were sent.

Hand-made links work too: ?score=<url>&map=<url>.

Part of the visualizers project. Supports MusicXML partwise and timewise scores.
